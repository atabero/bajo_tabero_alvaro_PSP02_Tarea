
# Lectores y Escritores

Aplicación Java que gestiona el acceso concurrente a un fichero
de texto mediante semáforos (`Semaphore`).

## Objetivo

Implementar el problema clásico de lectores y escritores,
permitiendo consultas simultáneas y escrituras exclusivas.

## Tecnologías

- Java 25
- Semaphore
- Git

## Estructura

```text
lectores-escritores/
├── src/
│   └── Main.java
├── paises.txt
├── .gitignore
└── README.md
```

## Ejecución

Ejecutar la clase `Main`.
